测量数据管理系统 1.1.0

安装完成后，可通过桌面快捷方式或开始菜单启动本软件。

系统要求
--------
Windows 10 / Windows 11，64 位系统。

软件说明
--------
本程序用于水准测量数据处理，包含闭合/附合水准路线计算、误差分析、
CSV / Excel 成果导出和工程文件管理。

安装包已包含 Python、PySide6、Qt 和 VC 运行库，不需要另外安装 Python
或配置环境变量，也不需要联网运行。

数据与日志
----------
工程文件和导出成果保存在用户选择的目录。
诊断日志位于：
%LOCALAPPDATA%\SurveyingTools\测量数据管理系统\logs\app.log

卸载
----
可在 Windows“设置 → 应用”中找到“测量数据管理系统”并卸载，
也可以运行安装目录中的 unins000.exe。
