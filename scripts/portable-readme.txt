测量数据管理系统 - 便携版

运行方式
--------
解压整个文件夹后，双击 SurveyingDataManager.exe 即可运行。
不需要安装 Python，不需要配置环境变量，不需要联网。

系统要求
--------
Windows 10 / Windows 11，64 位系统。

重要说明
--------
1. 请保持文件夹完整，不要只复制 SurveyingDataManager.exe。
2. 工程文件和导出的 CSV/Excel 文件默认保存在用户选择的目录。
3. 若程序被杀毒软件拦截，请将整个文件夹加入信任区。
4. 若启动缓慢，请优先使用本便携版：它避免了单文件版每次启动解压的开销。

诊断日志
--------
%LOCALAPPDATA%\SurveyingTools\测量数据管理系统\logs\app.log

遇到异常时，请在软件菜单“帮助 → 打开诊断日志目录”中查看日志。
